PolicyLens

Policy data quality checks for insurance spreadsheets. It reads a customer sheet and reports what a human must verify. Blank cells stay unknown, never guessed. Expiry dates are never read as renewal status.

View on GitHubRead the docs

What it checks

Blank cells

Reported as unknown, row by row and column by column. The tool never fills a missing value by guessing, borrowing another customer's value, or inventing a plausible one.

Duplicate customers

Matches on name and phone so the same customer does not get called twice or quoted two different renewals.

Expiry dates

Listed with an explicit warning that they are historical. Renewal status is verified with the customer or a verified policy source, never inferred from the sheet.

Optional AI helper

For every flagged customer, PolicyLens drafts short verification questions for the renewal call. Without an API key it is fully rule-based and works offline. Set an Anthropic API key and the Claude API phrases the questions for you. The tool never states a customer's current insurer or premium as fact; those always come from the customer.

Run it

pip install -e .
python -m policylens.checks your_sheet.xlsx
